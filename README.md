# de-ai: 去除中文文本的 AI 味与降低 AI 率

> 针对中文文本的“去 AI 味”改写与 AI 检测对抗 Skill，提供统计学代理指标量化体检、七条核心改写规则与分场景适配。

---

## 💡 核心认知

**这是对抗问题，不是优化问题。** 

目标是降低被 AI 检测器（朱雀、GPTZero、Turnitin、知网 AI 等）判定为生成内容的概率。目前检测器主要基于困惑度（Perplexity）、突发性（Burstiness）、模板结构等统计特征进行判定。

本 Skill 的核心方法论是 **「先量后改，改完再量，闭环迭代」**，拒绝无依据的盲改。

---

## 🛠️ 工作流

```text
量基线 (Baseline) ──> 按规则改写 (Rewrite) ──> 指标对比 (Compare) ──> 达标交付 / 迭代
```

1. **量基线**：运行体检脚本评估文本四个维度的表现：
   ```bash
   python scripts/metrics.py 原文.txt
   ```
2. **针对性改写**：根据评判为 `[差]` 的维度，依照 `references/rules.md` 执行改写。
3. **对比验证**：对比改写前后的代理指标并检查达标情况：
   ```bash
   python scripts/metrics.py --compare 原文.txt 改写后.txt
   ```

---

## 🎯 达标指标参考

| 维度 / 指标 | 目标值 | 意义 |
|---|---|---|
| **句长变异系数** | ≥ 0.55 | 打破机器均匀句长，制造长短交错 |
| **相邻句长变化率** | ≥ 0.50 | 避免连续相似长度句子 |
| **短句占比 (<15字)** | ≥ 15% | 增加态度表达与节奏突发性 |
| **模板词密度** | < 2 / 千字 | 剔除套路连接词、官腔公文套话 |
| **标点种类** | ≥ 5 | 引入破折号、问号、括号、省略号等 |
| **段落长度变异系数** | ≥ 0.35 | 避免段落等长分布（≥3段有效） |

## 📐 七条核心改写规则速查

1. **句长长短交错（权重最高）**：每 2–3 句穿插一个短句（<15 字），长句承载信息，短句承载态度与结论。
2. **拆掉模板连接词**：彻底删除“首先/其次/综上所述/值得注意的是/显而易见/不仅而且”等套话。
3. **打破排比与对称**：三项对称并列改为不对称结构或两项。
4. **添加限定条件**：把全称肯定/绝对判断改为有前提、有概率的真实现实判断。
5. **抽象具象化**：在概括名词后补充具体细节、数字或场景。
6. **适度口语与微量冗余**：引入“说白了/其实/说到底”，根据场景调控力度。
7. **丰富标点形态**：破折号解释、设问句反问、括号补充、省略号留白。

详细规则及示范请参阅 [references/rules.md](references/rules.md) 与 [references/example.md](references/example.md)。

## 📦 安装与使用

### 作为 DeepSeek Harness (DSH) Skill 使用
将本仓库克隆或解压至你的 DSH skills 目录下：
```bash
# Windows
git clone https://github.com/ElioChen240/de-ai.git C:\Users\<Username>\.dsh\skills\de-ai

# macOS / Linux
git clone https://github.com/ElioChen240/de-ai.git ~/.dsh/skills/de-ai
```
在 DSH 会话中直接发送指令（如输入 `/de-ai` 或“帮我把这段话去掉 AI 味并降低 AI 率”），Agent 会自动调用该 Skill 开展工作流。

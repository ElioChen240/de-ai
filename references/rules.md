# 去 AI 味改写规则手册

## 一、检测器在看什么

朱雀、GPTZero 这类检测器本质是**统计分类器**，主要抓五个特征：

| 特征 | AI 文本的表现 | 人的文本 |
|---|---|---|
| **困惑度** | 低 —— 每个词都是最"顺"的选择 | 高 —— 会有意外的用词 |
| **突发性** | 低 —— 句长方差小，节奏均匀 | 高 —— 长短句剧烈交错 |
| **模板密度** | 高 —— 连接词、结构词规整出现 | 低 —— 靠内容承接逻辑 |
| **标点多样性** | 低 —— 几乎只有逗号和句号 | 高 —— 破折号、问号、括号、省略号 |
| **段落均匀度** | 高 —— 每段长度接近 | 低 —— 长短不一 |

**改写目标 = 提高困惑度 + 提高突发性 + 破坏模板结构。**

注意：这是**对抗问题**。检测器会更新，规则需要跟着迭代。没有一劳永逸的写法。

## 二、七条核心规则

### 规则 1：句长必须长短交错（权重最高）

AI 的句长集中在 25–40 字。人写作会在 8–45 之间剧烈跳动。

**做法**：每 2–3 句里塞一个短句（<15 字）。短句适合放判断、强调、转折。

- 反例：`它能够显著提升写作效率，帮助研究者快速完成初稿。`
- 正例：`好处很直接：写初稿快。`

短句不是硬凑的，它承载的是**态度**和**结论**，不是信息。信息放长句，态度放短句。

### 规则 2：拆掉模板连接词

**黑名单**（见到就删或换）：

```
首先 / 其次 / 再次 / 最后
综上所述 / 总而言之 / 总的来说 / 总体而言
值得注意的是 / 需要指出的是 / 需要注意的是
由此可见 / 不难看出 / 显而易见 / 众所周知
毋庸置疑 / 不可否认 / 毫无疑问
与此同时 / 在一定程度上 / 从某种意义上说
随着…的发展 / 在当今社会 / 在…的背景下
不仅…而且 / 一方面…另一方面
发挥重要作用 / 起到关键作用 / 具有重要意义
提供有力支撑 / 奠定坚实基础 / 注入新动能 / 迈上新台阶
不可或缺 / 日益广泛 / 高度重视 / 深入推进
```

**做法**：直接删。段落间的逻辑靠内容承接，不靠连接词。

必须保留逻辑关系时，换成口语化的：`还有一点` `另外` `说回正题` `但问题也跟着来`。

### 规则 3：打破排比和整齐并列

AI 爱写三项并列，且每项结构一致。人写作常是不对称的。

**做法**：三项改两项；或把其中一项展开成句子、另一项压缩成短语。

- 反例：`提升效率、减轻负担、优化表达`
- 正例：`效率高，负担也轻。表达这块它确实能帮上忙。`

### 规则 4：降低"完美度"，加入限定

AI 的表述过于周全，每个论断都无懈可击。人会加限定、会承认不确定。

**做法**：加 `大概` `基本` `多数情况下` `我见过` `某种程度上`；
把绝对判断改成有条件判断（`这能提升效率` → `这通常能提升效率，但要看场景`）。

### 规则 5：增加具体性

AI 停在抽象层。人给具体例子、数字、场景。

**做法**：抽象名词后面补一个具体例子。

- 反例：`可以辅助文献综述的整理工作`
- 正例：`以前攒一篇综述要熬好几个晚上，现在半小时能出个能看的版本`

### 规则 6：允许口语化和轻微冗余

AI 追求简洁。人会有补充、重复、自我修正。

**做法**：适度加 `其实` `说白了` `这点` `话说回来` `倒不是说` `说到底`。

**注意**：这条要按场景收敛，学术和公文慎用（见第三节）。

### 规则 7：标点要丰富

AI 几乎只用逗号和句号。

**做法**：
- 破折号 `——` 做插入补充
- 问号 `？` 自问自答
- 括号 `（）` 夹注
- 省略号 `……` 表停顿
- 冒号 `：` 引出展开

## 三、按场景调整力度

| 场景 | 重点规则 | 收敛规则 |
|---|---|---|
| **学术论文** | 1 / 2 / 3 / 7 | 6 要收敛，少口语 |
| **公文报告** | 1 / 7 | 6 禁用；很多模板词是体例要求，不能删 |
| **自媒体文案** | 全部 | 6 可以拉满 |
| **小说叙事** | 1 / 5 / 6 / 7 | 句式节奏是命门 |

**学术场景的关键认知**：学术腔 ≠ AI 腔。严谨的长句没问题，问题是**没有短句穿插**。
学术文本的改法是"长句之间插判断句"，不是"把长句改短"。

---

## 四、常见改坏的地方

1. **过度口语化** —— 学术文本改成了朋友圈，体裁崩了
2. **连接词删过头** —— 逻辑断裂，读不懂。删的是套话，不是逻辑
3. **只做同义词替换** —— 那是"降重"不是"去 AI 味"，模板结构还在，AI 味反而更明显
4. **动了事实** —— 数字、专名、引用、因果关系一个字都不能改
5. **长短句硬凑** —— 短句必须自然，不能每段都硬塞一句短的
6. **删掉了必要的限定** —— 把"通常"改成"一定"，事实强度被拔高了

## 五、迭代流程

```
1. 跑 metrics.py 拿原文基线
2. 按规则改写（优先修「差」的维度）
3. 跑 metrics.py --compare 看改善
4. 未达标项针对性再改一轮
5. 达标后，抽样送真实检测器（朱雀网页版）验证
6. 把真实结果记下来，回头校准参考区间
```

**关于阈值**：`metrics.py` 里的参考区间是经验值，来自"人 vs AI 文本的一般统计差异"。
它不是检测器的替代品。跑过几轮真实检测后，按你自己场景的数据调整阈值。

## 六、自检清单

改写完成后逐条过：

- [ ] 每 2–3 句至少有一个短句（<15 字）
- [ ] 模板词黑名单一个不剩
- [ ] 没有三项整齐并列
- [ ] 至少一处破折号 / 问号 / 括号 / 省略号
- [ ] 有具体例子或数字，不是纯抽象论述
- [ ] 数字、专名、引用、因果关系与原意完全一致
- [ ] 读一遍：像不像一个真人在跟你说话
